# 内容管理模块使用手册

## 模块简介
本模块为运营团队提供统一的内容资产管控、沟通标准化管理及自动化质量监控能力。模块覆盖素材上传与分发、敏感词过滤、标准化话术维护以及基于规则引擎的质检流水线。通过内置的AI增强服务与埋点追踪机制，实现内容合规性自动检测、客户阅读行为分析、话术智能推荐及质检预警闭环，解决多端内容分散、人工审核效率低、沟通标准不统一及质量数据难以量化等问题。

## 核心功能
### 素材全生命周期管理
支持素材的创建、更新、删除与详情查看（对应接口 `/materials`）。运营人员可对素材进行自定义分类管理，并通过专属链接生成与分享统计功能实现内容对外分发。模块集成内容埋点追踪服务，自动记录素材的浏览、阅读时长及分享行为，并基于客户互动数据自动生成标签，辅助运营评估内容吸引力。

### 敏感词库与合规检测
提供敏感词的增删改查及批量导入能力（对应接口 `/sensitive-words`），支持按类别与严重程度划分词库。系统内置合规检测服务，在素材上传或发布前自动扫描文本内容中的敏感词匹配情况，并持续沉淀敏感词命中记录，便于追溯违规源头。

### 标准化话术库管理
提供话术的集中维护与检索能力（对应接口 `/scripts`）。支持按分类浏览话术列表，记录每次话术的实际调用次数以评估使用热度。结合AI增强服务，系统可根据上下文自动生成话术草稿，并提供智能推荐功能，帮助运营快速构建高转化沟通模板。

### 自动化质检引擎
基于可配置的规则引擎对业务内容进行质量评分与合规审查（对应接口 `/inspection-rules` 与 `/inspection-results`）。运营人员可灵活创建、修改或删除质检规则，设定触发条件、执行动作、严重等级与优先级，并通过开关控制规则生效状态。系统实时输出质检结果，支持人工复核操作，并汇总展示质检统计数据。

## 常见操作流程
### 流程一：素材上传、分类与分享
1. 进入控制台「素材管理」页面，完成素材文件上传或文本录入。
2. 选中目标素材，调用分类管理接口将其归入指定业务分类。
3. 发起合规检查请求，确认内容通过敏感词与合规校验。
4. 生成素材分享链接，并在分发后通过分享统计面板查看触达效果。

### 流程二：敏感词批量导入与命中排查
1. 准备符合格式的敏感词清单，通过批量导入接口一次性写入词库。
2. 根据业务需要调整单个敏感词的类别、正则匹配模式或启用状态。
3. 定期拉取敏感词命中记录，定位触发拦截的具体业务场景与关联内容。

### 流程三：话术创建、使用记录与AI推荐
1. 在控制台「话术库」页面新建话术，填写标题、分类、正文内容及变量占位符。
2. 业务人员在实际沟通中调用话术，系统自动累加该话术的使用次数。
3. 遇到新场景时，提交需求至AI推荐接口，获取结构化话术草稿供二次编辑。

### 流程四：质检规则启用与结果复核
1. 通过质检相关后台入口新建质检规则，配置规则名称、类型、触发条件、执行动作、严重等级与优先级。
2. 开启规则开关使其投入生产环境，系统将自动对流入内容进行流水线质检。
3. 在质检结果列表中查看命中详情，针对存疑案例执行人工复核操作。
4. 查阅质检统计看板掌握整体质量趋势，接收预警通知并完成工单处置。

## 相关配置说明
本模块的配置项主要围绕规则引擎、预警通道与行为埋点展开，所有配置均作用于当前租户隔离环境。

质检规则配置需明确定义触发条件集合、对应的执行动作、严重等级划分及优先级排序。规则状态分为启用与停用，切换状态将即时影响后续内容的质检流向。质检结果记录包含来源类型、来源标识、命中内容片段、采取的动作、复核人与复核时间等字段，用于完整还原审核轨迹。

预警通知配置依托于预警模型，需指定通知渠道、接收对象及状态流转逻辑。当质检结果触发预设条件时，系统自动生成预警事件，运营人员可在预警列表中查看未处理事项，并通过处置接口完成状态更新与责任人指派。

内容埋点追踪配置由系统底层自动接管，无需手动干预。埋点数据涵盖用户标识、事件类型、交互持续时间及扩展元数据，直接映射至素材分析服务，为自动打标签与使用统计提供数据基座。敏感词库配置支持正则表达式匹配模式切换，运营人员可根据实际拦截精度要求调整匹配策略。话术变量配置允许在正文中预留动态替换占位符，确保话术在实际调用时能够适配不同客户信息。
